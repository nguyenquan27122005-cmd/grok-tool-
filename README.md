# grok-tool

Public source for a modular Grok / xAI registration helper.

**All runtime secrets stay on your machine.** Copy `grok_tool/config.example.json` to `grok_tool/config.json` locally. Never commit `config.json`, account lists, Chrome profiles, or Google credentials.

See [`grok_tool/README.md`](grok_tool/README.md) and [`grok_tool/SAFE_GITHUB.md`](grok_tool/SAFE_GITHUB.md).
